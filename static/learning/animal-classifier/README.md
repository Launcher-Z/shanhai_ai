## 第4课4.1共用实验

4.1按活动ID读取`beasts/dataset.json`，使用`beasts/images/`的40张现实动物训练图和4张异兽测试图，均原样复制自教学目录`2.3 图像识别优化/活动：能识别山海经的动物么/`。短尾猴、果子狸、穿山甲、章鱼各10张；测试图按何罗鱼、鯥（旧名陸.png）、天狗、长右排列，44个文件SHA256无重复。

四类名称固定，学生从对应图库选图，每类至少2张，可全选10张；底层共用本地MobileNet特征模型和softmax分类层。界面、状态恢复和概率动画按类别数处理。4.1仅提供图片测试，2.2继续提供原两类、九图和摄像头。两个活动的iframe实例与本地存储按活动ID隔离。

4.1札记仅有16格百分比，固定四列名称，由学生手填。缺项可暂存，提交须填全、范围合法且各行合计100（允许0.2的舍入误差）；不判模型预测对错、不需审核、提交变绿，不自动评金圈。教师端按题目快照还原四列表格，沿用worksheet_records，不新增表。详细设计见`docs/第4课课堂设计.md`。

教师端“札记分析”的2.2任务包含10组双柱图（9张固定图片与摄像头），随顶部全部班级/指定班级筛选，展示金丝猴/雪豹的平均预测百分比和有效人数。只读正式提交的首答快照，按类别名称对齐学生列顺序；缺失、非法数值、重复字段、合计异常或类别名不明确的来源不进入均值，0和100仍合法。摄像头画面不同，均值只用于描述。

点击柱组查看来源学生、班级、题目版本、学生原值及原札记链接。可以按学生的单个来源排除或恢复，原因选填；标记单独保存在`animal_analysis_exclusions`，由札记记录ID、来源编号和提交快照指纹确定，不修改答案、首答、成绩、圈色或课堂进度。标记在全部班级/指定班级视图间共用，重启仍保留。新建表由应用启动时的`init_db`创建，已运行的服务需重启以加载新代码。

统计模块为`shanhai/animal_analysis.py`，教师会话接口为`GET/POST /teacher/animal-analysis`。返回`names`与`rows`：每组含`means`、有效/异常/排除/缺失人数及`sources`；没有有效来源时`means`为null，不伪装成0。写操作沿用CSRF校验，并核对班级范围和来源指纹。针对性检查见`tests/test_animal_analysis.py`。

当前素材入口：训练只从内置图库选图，图片测试只提供9张固定图；已移除个人照片上传、“＋”上传占位和训练拍照入口，仅保留摄像头实时测试。旧本机记录中的个人照片编号移出训练集，原结果和服务器札记保留，调整后的训练集需重新训练。

视觉沿用项目的中式古籍风格：半透明纸笺、楷体标题、墨绿与朱砂配色、壹贰类别签、朱砂训练印和古纸图库弹窗；照片保留原色、预测数值使用等宽字体。三栏结构与训练、测试、札记流程保持一致。

预测结果的条形与百分比同步平滑过渡：图片测试约600ms、实时摄像头约220ms，新预测从当前显示值继续变化。动画只影响展示，札记由学生观察数值自行填写；系统设置减少动态效果时直接显示结果。

札记结果表采用局部的`note-animal-record`样式：类别名与百分比单位分层、两列墨绿/朱砂呼应预测条、细横线与居中等宽数值，不改变字段、文字序列化和提交格式。

测试区上方使用“图片测试／摄像头实时测试”标签。图片模式只提供9张固定测试图，不提供个人照片入口；实时模式直接显示摄像头画面和两类预测比例，单帧完成后再延迟250ms安排下一帧，不并发堆积。切换模式、修改训练集、训练、关闭活动或页面隐藏都会停止摄像头；刷新后默认图片模式，不自动申请权限。实时推理不保存画面、不新增操作流水、不写入9图札记结果；训练区只从内置图库选图。普通HTTP或权限失败时提示切回图片测试。

当前2.2合并原2.2训练和2.3测试，活动ID为`lesson-2-task-2`。2.1人工识别独立保留。

## 本地模型与依赖

- TensorFlow.js 4.22.0：`https://cdn.jsdelivr.net/npm/@tensorflow/tfjs@4.22.0/dist/tf.min.js`
- MobileNet适配器2.1.1：`https://cdn.jsdelivr.net/npm/@tensorflow-models/mobilenet@2.1.1/dist/mobilenet.min.js`
- 预训练MobileNet V2 0.50/224：官方Kaggle下载`https://www.kaggle.com/api/v1/models/google/mobilenet-v2/tfJs/050-224-classification/2/download`，解包为`model/model.json`和两个权重分片。Apache 2.0，许可证见`vendor/LICENSE`。
- 按官方适配器要求使用`inputRange:[0,1]`，读取1280维全局池化特征；L2归一化后，通过80轮全批量梯度下降训练softmax线性分类层。测试只前向计算，不更新参数。
- 依赖、模型、图片均由教师机提供；仅进入本活动且需要推理时加载运行库和预训练模型，不在学生页面调用外网。
