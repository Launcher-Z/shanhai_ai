损失怎样得到？

取出模型分配给正确类别的预测比例 p，再计算：损失 = −ln(p)。

点击“预测结果”后，可查看本次损失计算。

这里使用交叉熵损失，ln 是自然对数。正确类别的预测比例越接近 1，损失越接近 0；只看类别猜对或猜错，无法判断误差的大小。

参数怎样调整？

权重改变量 = 学习率 ×（目标值 − 预测比例）× 输入值
偏置改变量 = 学习率 ×（目标值 − 预测比例）

正确类别的目标值为 1，另一类别为 0。类别猜对时，损失仍可能不为 0，参数仍会调整；输入值为 0 的位置，当前一步权重不变。
