参数怎样调整？

权重改变量 = 学习率 ×（目标比例 − 预测比例）× 输入值
偏置改变量 = 学习率 ×（目标比例 − 预测比例）

正确类别的目标比例为 1，其他九类为 0。输入为 0 的位置，本次权重不变，偏置仍可变化。
