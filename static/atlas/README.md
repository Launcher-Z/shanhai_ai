# 五藏山经地图模型

本轮范围是南、西、北、东、中五篇山经。使用郭璞注本公有领域正文，剔除注疏后分段整理为 26 条山系、447 处山域。条目数指所选版本中可提取的逐山记录，非古籍篇末自计山数。

## 预览

正式 Flask 应用启动后，访问 `/static/atlas/index.html` 即可，不需要 Node.js 或联网。也可双击 `sketches/3/start-preview.cmd`，使用已确认的 `E:\Anaconda\envs\shanhai-ai` 环境启动独立预览。模型代码和资源均在本目录，可直接由现有 Flask 的静态文件路由提供。

正式学习首页 `/learn` 的顶栏已加入“山海图”入口。点击后通过 `index.html?embed=1` 复用本目录地图，隐藏独立预览中的示例课程；外层原生模态窗口负责阻止背景交互、关闭按钮和焦点返回。地图内按 Esc 同样可以关闭。每次打开创建 iframe，关闭时释放场景并卸载 iframe，不在后台保留 WebGL。图片仍从 `../bestiary/index.json` 读取，可与插画生成任务并行维护；新接入的图片在下次打开地图时读取。学习页接入没有新增后端接口或数据库字段，当前解锁仍为演示。

## 原文与艺术演绎

26 条山系拼接为一张连续写意地图，整体压成 3×3 共九个教学逻辑区域，单区边长 160、全图 480×480。山体内部紧凑蛇形排布，保留山系原文先后；不再用模型坐标表达原文方位或里程。里数与方向保留在介绍文字中，模型位置不是实际地理位置。底部全图仅显示当前位置，区域跳转按钮和寻山列表已移除，主要通过拖动探索。山形、峰高、皴线和水道弯曲形态为艺术演绎；“无草木”时减少植被，“四方而三坛”用于台地形态。

九域暂按下表编号，预留给九个课时；此分区不是《山经》原有的九篇。山系保持完整，447 处山域不重不漏：

| 第4域：西山前段 | 第5域：北山前段 | 第6域：北山后段 |
| --- | --- | --- |
| 第3域：西山后段 | 第9域：中山中境 | 第7域：东境 |
| 第2域：中山西南 | 第1域：南境 | 第8域：中山东南 |

具体对应山系见 `terrain.js` 的 `ZONES`，可在确定教学节奏后调整编号。

地图覆盖层与 WebGL 背景均透明，独立预览中可见的纸色来自下方课程页面。五域采用苔青、淡赭、青黛、水碧、苍石配色，地表、树冠、水面与侧壁在区域交界处混色。左上显示山经、山系与山名，切换带短暂淡出淡入；按空间距离设置小范围迟滞，减少交界处闪动。启用减少动态效果时直接换字。

右侧依次显示山名、生物、植物／矿物资源、折叠原文，无记载的栏目隐藏。`creatures`、`plants`、`minerals` 均为 `{name,text}` 数组，通过原文明示的命名、物产句式和物产词表整理，可点击展开原文记载。复杂叙事、生僻名称和后置记载仍可能未进入分类索引，完整山域原文始终可阅读，不声称已经完成逐条学术校勘。不同版本的异体字保留，系统字体无法显示的生僻字需要后续补字形。

右侧顶端对齐，使用内部原生滚动；自定义不等宽墨痕滑块同步进度，支持拖动及键盘，内容变化时按需更新。首批狌狌、凤皇、精卫提供透明水墨插画，展开后左图右文，窄屏上下排列；图片在展开后按需加载。素材、生成清单、提示词及后续接入步骤集中在 `static/bestiary/README.md`，九尾狐候选未通过尾数检查，暂未接入。

## 性能和交互

- 画质固定为轻量：48×48 网格（4,608 个地表三角形）、像素比最高 1，不提供其他画质选项；只采样附近山体，远处山峰跳过昂贵的细节计算。
- 树冠、树干和石块使用实例化绘制，数量有上限。等高墨线与五片静态雾片代替动态云体，没有实时阴影、反射和全屏后处理。
- 不运行持续动画循环；仅在拖动、缩放、切换、窗口尺寸变化时绘制，地形更新合并至约每 42 毫秒最多一次。关闭模型释放几何体、材质、画布与监听器。
- 支持拖动、缩放、双指缩放、转动视角、键盘、Esc、焦点约束及窄屏排版。
- 解锁进度明确为预览演示；尚未接入真实学习记录。按第 1—9 课逐区开放，边界按九宫格单元判断，不再按百分比切割山系。未开放山峰不参与地形采样。

数学采样、数据和资源加载检查不代表课堂设备实测帧率；视觉及设备性能仍需浏览器验证。
