再绘山海经 · AI 课堂平台 (v1.0.1) 使用说明
==============================================

本版本已内置全部运行环境，无需安装 Python 或其他任何软件，解压后即可使用。

一、启动步骤
1. 将整个文件夹解压到电脑任意位置（不要直接在压缩包内双击运行）。
2. 双击运行“启动课堂.bat”，打开图形化启动器窗口。
3. 可按需调整端口（默认 5000）、并发线程数（默认 8）、是否开启课程进度解锁及局域网 HTTPS（默认开启，支持学生端使用摄像头）。
4. 点击“▶ 启动课堂服务”，会自动打开教师控制台（https://127.0.0.1:5000/teacher）。
5. 首次使用时，若浏览器提示“您的连接不是私密连接”，点击“高级 → 继续前往”即可；进入后先设置不少于 8 位的教师密码，并创建上课班级。
6. 点击启动器中的“复制”按钮，将“学生端地址”（如 https://192.168.x.x:5000）发给学生即可。

二、局域网摄像头与 HTTPS 说明
- 默认开启“启用局域网 HTTPS”：学生端在局域网内访问 https://192.168.x.x:5000 并点击一次“高级 → 继续前往”后，即可正常调用摄像头进行实时测试。
- 证书保存在独立目录 certs\（与学生数据目录 data\ 分离）：如果机房有批量部署条件，可点击启动器“导出HTTPS证书”导出根证书（ca.crt），通过极域或批处理（certutil -addstore -f Root shanhai_lan_ca.crt）导入学生机“受信任的根证书颁发机构”。导入后即使教师机以后更换 IP，只要保留 certs\ 目录，学生机也无需重装证书。
- 如无需使用摄像头，也可取消勾选“启用局域网 HTTPS”，切回普通 HTTP 模式。

三、启动器实用功能（建议停止服务后操作）
- 一键备份数据库：将当前数据库、学生作品附件与会话密钥完整备份到 data\backups\backup_时间戳\。
- 备份并初始化数据库：先自动备份当前数据，再清空重建空白课堂数据库，方便换班或新学期重新开始。
- 重置教师密码：可直接输入不少于 8 位的新密码，或留空清除密码以恢复首次设置向导。
- 导出HTTPS证书：导出当前局域网自签名证书（.crt），供机房批量信任使用。
 - 打开文件夹 release\v1.0.1\data\certs\，双击 server.crt。
 - 点击 「安装证书...」。
 - 存储位置选择 「当前用户」（或选「本地计算机」让本机所有用户生效，需管理员权限），点「下一步」。
 - 选择 「将所有的证书都放入下列存储」 → 点击 「浏览...」 → 选中 「受信任的根证书颁发机构」 → 点「确定」。
 - 点「下一步」→「完成」，弹出安全警告时点 「是」。
 - 重启浏览器（Edge / Chrome 需完全关闭所有窗口再重开），再次访问 https://127.0.0.1:5000 或局域网 IP 即可直接信任。

- 打开数据目录：快速打开 data\ 文件夹，方便拷贝或归档课堂备份。

四、注意事项
- 课堂进行期间请保持启动器窗口开启，关闭窗口即停止服务。
- 如果学生机无法访问，请在 Windows 防火墙弹窗中点击“允许访问”，或检查是否处于同一局域网。
